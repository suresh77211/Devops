Step 1: Set Hostnames and Update OS
On both master and worker:
sudo hostnamectl set-hostname master    # or worker
sudo yum update -y                      # or sudo apt update && sudo apt upgrade -y


Add entries in /etc/hosts on both:
sudo nano /etc/hosts

172.31.46.22   master
172.31.32.176  worker1
172.31.41.12   worker2

<Master-IP>  master
<Worker-IP>  worker

Step 2: Disable Swap & Set Kernel Params
On both nodes:

sudo swapoff -a
sudo sed -i '/swap/d' /etc/fstab

cat <<EOF | sudo tee /etc/modules-load.d/k8s.conf
br_netfilter
EOF

cat <<EOF | sudo tee /etc/sysctl.d/k8s.conf
net.bridge.bridge-nf-call-ip6tables = 1
net.bridge.bridge-nf-call-iptables = 1
EOF

sudo modprobe br_netfilter
sudo sysctl --system

Step 3: Install Docker (or containerd)

For Docker:

sudo yum install -y docker    # Amazon Linux / CentOS
sudo systemctl enable --now docker

Step 4: Install Kubernetes Components

On both nodes:

cat <<EOF | sudo tee /etc/yum.repos.d/kubernetes.repo
[kubernetes]
name=Kubernetes
baseurl=https://pkgs.k8s.io/core:/stable:/v1.30/rpm/
enabled=1
gpgcheck=1
repo_gpgcheck=1
gpgkey=https://pkgs.k8s.io/core:/stable:/v1.30/rpm/repodata/repomd.xml.key
EOF

sudo yum install -y kubelet kubeadm kubectl
sudo systemctl enable --now kubelet


Install and Configure containerd (Runtime) (Both master and worker){
sudo yum install -y containerd
sudo mkdir -p /etc/containerd


containerd config default | sudo tee /etc/containerd/config.tom
Edit this config file to enable SystemdCgroup (required by Kubernetes):

sudo nano /etc/containerd/config.toml

Find this section:

[plugins."io.containerd.grpc.v1.cri".containerd.runtimes.runc.options]
  SystemdCgroup = false

Change false to true:

SystemdCgroup = true

sudo systemctl restart containerd
sudo systemctl enable containerd

# 2. Enable IP forwarding
echo "1" | sudo tee /proc/sys/net/ipv4/ip_forward
sudo sysctl -w net.ipv4.ip_forward=1

}


Step 5: Initialize Kubernetes Cluster (on Master)

sudo kubeadm init --pod-network-cidr=192.168.0.0/16

After a minute or two, you’ll see a message with kubeadm join command. Copy it.

Set up kubectl config for the root or a user:

mkdir -p $HOME/.kube
sudo cp -i /etc/kubernetes/admin.conf $HOME/.kube/config
sudo chown $(id -u):$(id -g) $HOME/.kube/config


Step 6: Install Pod Network (on Master)
kubectl apply -f https://raw.githubusercontent.com/projectcalico/calico/v3.27.0/manifests/calico.yaml

Step 7: Join Worker Node

sudo kubeadm join <master-ip>:6443 --token <token> --discovery-token-ca-cert-hash sha256:<hash>

Step 8: Verify Nodes (on Master)
kubectl get nodes

Disable swap (required by Kubernetes):

sudo swapoff -a
sudo sed -i '/ swap / s/^/#/' /etc/fstab

STEP 3: Install container runtime (containerd)

sudo yum update -y
sudo yum install -y yum-utils device-mapper-persistent-data lvm2
sudo yum install -y containerd

sudo mkdir -p /etc/containerd


Edit config to enable systemd cgroup driver:

sudo sed -i 's/SystemdCgroup = false/SystemdCgroup = true/' /etc/containerd/config.toml

Restart and enable containerd:

sudo systemctl restart containerd
sudo systemctl enable containerd

Add Kubernetes YUM repo and install tools

cat <<EOF | sudo tee /etc/yum.repos.d/kubernetes.repo
[kubernetes]
name=Kubernetes
baseurl=https://pkgs.k8s.io/core:/stable:/v1.30/rpm/
enabled=1
gpgcheck=1
gpgkey=https://pkgs.k8s.io/core:/stable:/v1.30/rpm/repodata/repomd.xml.key
EOF

STEP 4: Install Kubernetes (kubeadm, kubelet, kubectl)

sudo yum install -y kubelet kubeadm kubectl

sudo systemctl enable kubelet
sudo mkdir -p /etc/apt/trusted.gpg.d
sudo curl -fsSL https://packages.cloud.google.com/apt/doc/apt-key.gpg | sudo gpg --dearmor -o /etc/apt/trusted.gpg.d/kubernetes.gpg
sudo mkdir -p /etc/apt/sources.list.d
echo "deb https://apt.kubernetes.io/ kubernetes-xenial main" | sudo tee /etc/apt/sources.list.d/kubernetes.list
sudo apt update



sudo systemctl enable kubelet
sudo systemctl start kubelet

Enable IP forwarding (both master and worker)
sudo sysctl -w net.ipv4.ip_forward=1

Make it persistent
To ensure it persists after reboot:

echo 'net.ipv4.ip_forward=1' | sudo tee -a /etc/sysctl.conf
sudo sysctl -p
