Step-by-Step SonarQube Installation
Step 1: Update your system

sudo yum update -y
Step 2: Install dependencies
sudo yum install java-17-amazon-corretto wget unzip -y
Ensure Java 17 is installed:

bash
Copy
Edit
java -version

Step 3: Create a non-root user
SonarQube won't run as root. Create a user:
sudo adduser sonar
sudo passwd sonar
Give it permission on the install directory:


sudo mkdir /opt/sonarqube
sudo chown -R sonar:sonar /opt/sonarqube

Step 4: Download and extract SonarQube
(As ec2-user or sonar user)

cd /opt/sonarqube
sudo wget https://binaries.sonarsource.com/Distribution/sonarqube/sonarqube-10.3.0.82913.zip
sudo unzip sonarqube-10.3.0.82913.zip
sudo mv sonarqube-10.3.0.82913 sonarqube
sudo chown -R sonar:sonar /opt/sonarqube


Step 5: Run SonarQube manually (first test)
Switch to the sonar user:


sudo su - sonar
cd /opt/sonarqube/sonarqube/bin/linux-x86-64
./sonar.sh start
Wait 30 seconds, then check:


tail -f /opt/sonarqube/sonarqube/logs/sonar.log
Step 6: Access SonarQube
