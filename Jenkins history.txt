If memory of the node is high perform the below action
You can safely delete old temp files that aren’t in use:
sudo rm -rf /tmp/*
Or more conservatively, delete only files older than a day:
sudo find /tmp -type f -mtime +1 -exec rm -f {} \;
Then check space again:
df -h /tmp
increase the memory
sudo mount -o remount,size=2G /tmp
